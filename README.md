# Incubyte Gmail Compose Assessment

## Project Overview
This repository contains the manual testing assessment for Gmail Compose functionality. The focus is on validating the ability to compose and send an email using the specified subject and body.

## Objective
Verify Gmail Compose functionality by sending an email with the following details:
- Subject: `Incubyte`
- Body: `QA test for Incubyte`

## Deliverables
- A documented test plan covering the Gmail Compose scenario.
- Test execution results for subject and body verification.
- Defect report if any issues are identified during testing.

## Scope of Testing
- Compose a new email in Gmail.
- Enter the specified subject and body text.
- Confirm message formatting and input acceptance.
- Send the email successfully.
- Validate that the email appears in Sent Items.

## Test Coverage
- Subject field entry and persistence.
- Email body composition and content accuracy.
- Send action behavior and success confirmation.
- Sent folder validation for the delivered email.
